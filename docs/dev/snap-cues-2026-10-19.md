# Snap cues

## Layout and interaction contract

- Desktop canvas: compact two-line snap name and pending constraint label beside the accepted snap marker.
- Constant 12px text, 8px padding, 18px line spacing; no changes to palette widths or canvas area.
- Clamp the label within the canvas and choose a position clear of editable dimension fields and the pointer. No interactive hit target or focus changes.
- Reflect the final snapped coordinate, not a stale hover after keyed/polar overrides. Clear on leaving the canvas, cancellation or loss of the snap.
- Read the same automatic-constraint setting used by the commit path. OFF identifies positioning only. Unsupported construction-point relations are not advertised as permanent constraints.
- Pending relation labels describe intent; solver acceptance remains required. No geometry, native data or solver behavior changes.
- Dev only. The separately reported Offset motion/decimal-entry failures remain open.

# Layer controls - Dev implementation contract

Scope: full DXFer editor on Dev only. Preserve existing Foundry colors, compact
controls, independent palettes and geometry editing. Right information rail is
18.5rem wide; active operation remains at the top, Layers beneath it. Rows use
fixed 28px icon targets and color swatches, flexible ellipsized names with titles,
and fixed entity counts. Names/edit fields wrap in the detail area; the layer
list scrolls internally. No floating cards, canvas overlap, or phone redesign.

Document metadata owns layer definitions and active drawing layer. Layer edits
participate in document history and native round trips. Plain DXF carries layer
name/color/off/locked flags. Hidden geometry remains in exports and cut totals;
hiding is not a manufacturing exclusion. Locked/hidden geometry cannot be
changed by selection or indirect solver edits. Layer 0 cannot be renamed/deleted;
nonempty layers cannot be deleted. No destructive merge/delete-contents action.

Verification: core layer operations and serialization, native/plain DXF import
and export, real canvas selection/drag/visibility/color, indirect locked-peer
protection, history/reopen, and desktop screenshots at 1440 and 1100px.

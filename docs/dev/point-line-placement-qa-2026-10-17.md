# Point-to-line dimension QA

Flux report: Slack1792265051.327539, Dev d8e284e. Point(5,3), Fixed
line(0,0)-(10,0). Dimension picks show yellow distance3, but empty-canvas click
does not place it. Status: OPEN; not yet locally browser-reproduced or fixed.

The intended gesture is select references, move the label, then click to place.
This is stated by the workbench Dimension prompt and implemented by
`handleDimensionToolClick` / `OnSketchDimensionPlacementRequested`.
No extra confirmation gesture is intended.

Native fixtures in `tests/DXFER.Blazor.Tests/fixtures/drag-matrix`:

- `point-to-fixed-line-placement.dxf`: Point(5,3), line(0,0)-(10,0), Fix line,
  no dimension. Reproduce placement in either pick order, avoiding endpoint
  picks when selecting the line body.
- `point-to-fixed-line-driving.dxf`: same geometry/Fix with a driving
  PointToLineDistance3, references [line,point], anchor(7,1.5). This bypasses
  placement only for independent drag testing; it is not proof that UI creation
  works. Horizontal point movement should retain y3 and the Fixed line.

Files are generated by the application's DxfDocumentWriter with native document
embedding and inch metadata. No live drawing or saved user record is changed.
